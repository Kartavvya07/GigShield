# GigShield

GigShield is an automated protection and safety net system for gig workers.

## Project Structure

```
gigshield/
│
├── frontend/        # Web / Mobile client application
│
├── backend/         # Server APIs and business logic
│
├── shared/          # Shared contracts, schemas, and sample data
│   ├── api-contract.md
│   ├── sample-data.json
│   └── README.md
│
└── README.md        # Project documentation
```

## Getting Started

1. **Frontend:** Check `frontend/` directory for frontend setup.
2. **Backend:** Check `backend/` directory for backend setup.
3. **Shared:** Refer to `shared/api-contract.md` for API specifications.
